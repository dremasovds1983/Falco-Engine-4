# Falco Engine 4 — предварительная версия

[English](README.md)

## Движок одной командой

На Windows x64 нужны Visual Studio 2022 (Desktop development with C++, MSVC v143,
Windows 10/11 SDK) и Git for Windows. PowerShell 5.1, входящий в Windows,
достаточен; PowerShell 7 также поддерживается. Для первой сборки рекомендуется
не менее 10 ГБ свободного места для исходников, кэша и временных файлов.

Скачайте или клонируйте этот репозиторий в короткий путь, например
`D:\FalcoDev`. Из корня выполните одну команду:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1
```

Команда сама скачает CMake и закреплённые исходники зависимостей с серверов
их разработчиков, проверит SHA-256 и соберёт зависимости, Engine, Editor и Player.
Mono скачивается как закреплённый пакет разработчика и распаковывается локально.
Большой общий архив зависимостей в GitHub не используется. Первый запуск требует
интернета и занимает существенно больше времени, чем повторная сборка.
Контрольные суммы локально собранных библиотек записываются в `out/local-locks`:
обновление Visual Studio вызывает пересборку зависимостей. Исходные версии и
контрольные суммы скачиваемых пакетов остаются закреплёнными в Git.

Результат: `out/falco/bin/Editor/Editor.exe` и
`out/falco/bin/Player/Player.exe`. Повторный вызов использует локальные
зависимости. Для полной пересборки добавьте `-Rebuild`.

## Установщик одной командой

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1 -Mode Installer
```

Движок будет собран, необходимые инструменты скачаны автоматически, результат:
`out/installer/FalcoEngineSetup.exe`. Если приложения уже собраны:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build-Installer.ps1 -SkipBuild
```

Используется [Inno Setup](https://jrsoftware.org/isinfo.php) в переносимом режиме.
Пакеты инструментов закреплены в InstallerTools.lock.json. Установщик включает
Editor, Player, общие ресурсы/Mono и Visual C++ x64 Runtime. Runtime устанавливается
только при отсутствии необходимой версии; Windows может запросить повышение прав.
Сам движок ставится для текущего пользователя в LocalAppData/Programs, где может
сохранять настройки и shader cache. У modern отдельный AppId и каталог; legacy
не заменяется. Ручная проверка интерфейса остаётся владельцу.

## Изменения и GitHub

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Push-Changes.ps1 -AllowPublic -Message "Исправление описанного бага"
```

Команда создаёт commit для изменённых исходников и выполняет обычный push.
Она проверяет, что origin совпадает с репозиторием в BuildSupport.lock.json; force-push
не используется. При конфликте push прекращается, локальный commit сохраняется.
Публичная отправка требует явного флага -AllowPublic. История прежнего приватного репозитория не включена в первую публикацию.

`.gitignore` исключает зависимости, результаты сборки и локальные проекты;
`.gitattributes` сохраняет точные байты файлов без автоматической смены LF/CRLF.
Исходники и сценарии хранятся в Git; скачанные зависимости и результаты сборки — локально в игнорируемых каталогах.

## Область этой версии

Исходники опубликованы как предварительная версия Falco Engine 4. Engine, Editor, Player и шейдеры собираются; ручная визуальная приёмка остаётся открытой. Изменения, ограничения и план проверки: [RELEASE_NOTES.md](RELEASE_NOTES.md). Имеющиеся LICENSE и notices сохранены.

## Совместимость после переименования

Пользовательское название движка — Falco. Для совместимости существующих
проектов сохранены C# namespace FalcoEngine и заголовки форматов
сериализации, каталог списка проектов FalcoEngine, имена сборочных скриптов. Репозиторий: https://github.com/dremasovds1983/Falco-Engine-4.
Новые результаты сборки создаются в out/falco.
Установщик Falco Engine сохраняет AppId modern-версии. Папка выбирается явно:
страница выбора показывается и при обновлении; по умолчанию Programs/Falco Engine.
Исторические copyright и notices исходного движка сохранены.

Текущая версия Falco — **4.0.0.0**. Управляемая сборка теперь называется
FalcoEngine.dll (assembly name FalcoEngine). При регенерации старого C#-проекта
редактор меняет ссылку и пересобирает пользовательские скрипты. Сторонние
предкомпилированные DLL, ссылающиеся на прежнюю сборку, нужно пересобрать
против FalcoEngine.dll; экспорт игры также следует выполнить заново.
Хэши нового API будут вычислены следующей разрешённой сборкой Build.ps1
в out/local-locks. Существующие output-хэши в исходном lock — исторические;
не использовать их как подтверждение нового бинарника без восстановления зависимостей.

После переезда локальный рабочий каталог — D:\Falco_engine\Falco.
Старый out/falco-modern сохранён как результат предыдущих сборок и не является
новым каталогом вывода. Не переносить его CMake/MSBuild-кэш в out/falco.
Исторические пути captureLogs в warning-baseline.json оставлены как свидетельства
прежнего прогона. Сборки приостановлены по указанию владельца; установщик —
только по отдельному прямому запросу.
