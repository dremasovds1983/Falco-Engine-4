# Изменения редактора — 2026-09-21

Статус: исходники изменены, **сборка и тесты не запускались** по указанию владельца.

- Window > Tags: общий реестр проекта, фильтр использования в текущей сцене,
  именованные избранные наборы и их явное копирование. Удаление оставляет пустую
  позицию с прежним ID; Show deleted / Restore восстанавливает имя. Новые теги
  добавляются в конец. Переименование не меняет ID в сценах/prefab, но строковые
  имена тегов в скриптах нужно обновлять вручную. Избранные наборы хранятся в
  настройках редактора проекта; автоматически от предыдущей сцены не наследуются.
- Window > Asset Browser: дерево каталогов, хлебные крошки, Back/Forward/Up,
  Icons (выключить для списка), поиск текущей папки, сортировка имени A-Z/Z-A,
  Ctrl для множественного выделения. Двойной щелчок открывает папку/ресурс;
  контекстное меню: открыть, переименовать, удалить с подтверждением, Проводник,
  перезагрузить. New folder использует существующее создание/редактирование в Assets.
  Обе панели работают с одним TreeView, выделением и ресурсами.
- Файлы из Проводника копируются в папку под курсором в Assets/Asset Browser,
  либо в корень Assets/текущую папку Browser при сбросе на пустое место.
  Поддерживаются несколько файлов. Существующие имена пропускаются с сообщением
  в Console; внешний оригинал остаётся. Файлы уже внутри Assets не копируются
  повторно — их нужно перемещать внутри редактора. Целые внешние каталоги пока
  отклоняются с сообщением. Неизвестные форматы сохраняются как обычные файлы;
  специализированный импорт определяется существующими импортерами движка.
- Assets и Hierarchy: Collapse all сворачивает вложенные узлы без смены выделения.
- Terrain: Add/Remove выбирает режим кисти травы, деревьев и detail meshes.
  Left Shift временно включает удаление. Удаление, как раньше, затрагивает все
  типы активной категории в области кисти; существующий механизм Undo/Redo сохранён.

Видимость Tags и Asset Browser, а также наборы избранного сохраняются в версии 5
Editor Settings с чтением прежних версий. UI-подписи английские в соответствии
с текущим интерфейсом; локализация остаётся отдельной задачей.

По команде владельца: собрать Engine/Editor, проверить новое/старое Editor Settings,
Tags (сохранение, ID после удаления, prefab, C#), внешнее перетаскивание Unicode-файлов,
коллизии/недоступные файлы/каталоги, обе asset-панели и dock/undock, внутренний drag,
переименование/удаление, сворачивание, Terrain Add/Remove/Shift/Undo/Redo.
Ни одна из этих проверок пока не объявлена PASS.
