# Редактирование prefab

Статус: сборка 2026-09-22 успешна (Engine / Player / Editor, ShaderSmoke). Интерактивная проверка владельцем ещё требуется.

Двойной щелчок по prefab в Asset Browser открывает вкладку `Prefab: <путь>` рядом
со Scene. Одинарный щелчок сохраняет прежний просмотр. Одновременно открыт один
черновик prefab; при переходе к другому предлагается сохранить или отменить правки.

Слева — дерево объектов, Add child/Delete и перенос дочернего объекта на другого
родителя. Корень нельзя удалить. Справа — предпросмотр; Move/Rotate/Scale работают
через gizmo. Свойства выбранного объекта находятся в обычном окне Inspector.
Есть добавление/удаление компонентов. Теги/слои выбираются из реестра проекта.

Save prefab записывает черновик; Discard changes возвращает последнее сохранённое
состояние. Undo/Redo отдельные от сцены (до 64 снимков / примерно 64 МБ истории).
Ctrl+S/Z/Y маршрутизируются к prefab, когда активно его окно или его Inspector.
При закрытии окна/редактора с изменениями есть Save/Discard/Cancel.
Перед сохранением проверяется, что исходный файл не изменился извне; запись идёт
через временный файл с заменой. Предыдущая версия сохраняется в Library/PrefabBackups.
Сохранение prefab не переписывает существующие экземпляры в открытой сцене.

Черновик — SScene в памяти. GameObject не создаются; Undo и объекты рабочей сцены
не заменяются. Предпросмотр использует отдельные render targets и view IDs, а не
runtime-компоненты. Загрузка сцены сбрасывает только кеш предпросмотра.

Ограничения первой версии:
- Визуализация мешей и decals; без симуляции скриптов, физики, частиц, Terrain/CSG/UI.
- Decal показан как albedo на нейтральной поверхности: это иллюстрация размера,
  ориентации и текстуры, не полная проверка проекции/освещения игрового рендера.
- Inspector использует формы сериализованных полей, не экземпляры компонентных
  редакторов. Часть расширенных перечислений пока числовая. Сложные массивы
  сохраняют длину; крупные массивы геометрии не редактируются в этой форме.
- Для замены MeshRenderer укажите/перетащите New model source и нажмите Load model.
  Если в модели несколько мешей, выберите часть в Model mesh. Это замена одного
  MeshRenderer; импорт всей иерархии модели отдельной командой пока не предусмотрен.
- Для встроенных примитивов нужен уже созданный кеш меша. При его отсутствии
  показывается сообщение; редактор не создаёт временные объекты в рабочей сцене.
- Материалы — общие ассеты. Open shared material открывает обычный MaterialEditor;
  его сохранения и Undo не относятся к отмене черновика prefab.

Проверить после разрешённой сборки: открыть BulletHoleTemp, сменить Scale и материал,
Undo/Redo, Discard, Save и повторное открытие; добавить/удалить DecalRenderer; дерево
с детьми и переносом родителя; переключение Scene/Prefab и сохранность сценового
Undo; закрытие/выход с изменениями; конфликт при внешнем изменении файла.

Откат самой функции: локальная резервная копия и Restore-PrefabMode.ps1 находятся в
D:\DreamOwl_engine\_ai\backups\prefab-mode-20260922. Скрипт сначала сверяет SHA-256
всех затронутых файлов и откажется затирать более поздние изменения. Он возвращает
состояние непосредственно перед Prefab Mode, включая прежние незакоммиченные
исправления. Пользовательские prefab и результаты сборок этим скриптом не меняются.

Известные проблемы на 2026-09-22:
- Зафиксированы падения при чтении материала в предпросмотре prefab и при
  освобождении предпросмотра после остановки рендера. Разбор продолжается;
  текущая сборка не считается исправлением этих аварий.
- Исправление конфликта фокуса Scene/Prefab и мигания Inspector собрано успешно
  (20260922-022559-365-25364); визуальная проверка владельцем ещё требуется.
- Серый Scene с пустой Hierarchy объяснялся включённой настройкой открытия
  проекта с пустой сценой. Связь сброса этой настройки с Legacy не подтверждена.
